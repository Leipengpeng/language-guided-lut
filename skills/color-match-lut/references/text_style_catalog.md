# 文字风格参考

可执行目录见 [style_catalog.json](../scripts/style_catalog.json)。风格名提供颜色方向，用户明确指定的颜色、反差、力度和保留项优先。例如「日系清新，阴影带一点青，保留自然肤色」。自定义风格也可直接使用。

## 可用风格

| 名称 | 常用检索别名 | 颜色方向 |
|---|---|---|
| 日系清新 | 日系小清新、通透、清透 | 明亮而保留高光，适度收敛饱和度，绿色／蓝色清爽，阴影有层次 |
| 韩系奶油 | 奶油感、奶油风、韩系 | 米白与温和暖意、柔和色彩、干净中间调；可被“冷奶油”等补充覆盖 |
| 复古港风 | 港风、港片色调、王家卫色调 | 暖色与青绿环境色对照、较厚的暗部、柔和高光；并非完整导演风格仿真 |
| 电影青橙 | 橙青、蓝橙、电影感 | 克制的青蓝暗部与暖色对照，保留肤色、黑位及亮部层次 |
| 赛博霓虹 | 赛博朋克、青紫霓虹 | 在已有明暗中加强青蓝、紫、洋红与冷暖对照，不改拍摄时段 |
| 美式复古 | 美式怀旧、美式胶片 | 暖琥珀、浓而不艳的红棕、稳重暗部，保留颜色区别 |
| 暖调胶片 | 胶片感、胶片风、复古胶片 | 温和暖亮部、柔和颜色过渡、收敛数码感；不承诺真实胶卷仿真 |
| 低饱和清冷 | 清冷、冷淡风、高级灰 | 综合色彩克制，中性灰白干净偏冷，减少过艳杂色而保留黑位与肤色 |
| 森系绿调 | 森系、氧气感、清透绿调 | 整理原有绿色，控制荧光绿，保持绿的深浅和暖色主体辨识度 |
| 法式油画配色 | 法式复古、油画色调 | 米白、暖杏、灰粉、收敛墨绿／棕色，柔和高光与暖静氛围 |
| 美漫配色 | 美漫、漫画配色 | 红蓝黄等色彩明确、明暗有力，保留摄影连续层次；仅满足用户给定画风词的颜色部分 |
| 黑白纪实 | 纪实黑白、黑白胶片、单色 | 有层次的黑白影调，亮暗有区别；原始彩色照片始终保留 |

「胶片」「电影」「森系」可涵盖多种配色。需要指定变体时，可补充色相、亮暗范围和变化力度。文字入口的默认档位为 natural，保持可信的色彩、曝光和光影。用户明确要求中等或浓烈效果时可选择相应档位。

## 应用范围

Image 根据压缩内容图和用户描述生成颜色参考。随后拟合一个全局 LUT，并套回本地原图。同一输入颜色在全图共享映射。颗粒、晕影、柔焦、局部补光、笔触和网点依赖位置或纹理，需要单独的编辑流程。
