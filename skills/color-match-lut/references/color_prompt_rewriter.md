# 调色指令转译工具

[打开离线页面](../assets/color_prompt_tool.html)。输入中文描述或粘贴语音转写，点击「生成调色指令」。先检查原话和保护项，再复制完整指令。将指令与准备好的内容 JPEG 一同交给 Image。核对 Image 的实际返回图后，再用它做一对一 LUT 追色。

页面使用本地词表和规则，无需服务、账号或图片。也可用 [通用转译提示词](color_prompt_system_prompt.txt)，将末尾占位符换成原话，再核对动作、保护项和最终指令。摄影师姓名、作品名、相机风格和其他专名保留原文。离线页面默认指令包含用户原话和固定保护项。给出风格、作品、导演或摄影师时，由 Agent [自动研究样张](style_reference_search.md)，有可用方向时可用[双图引导](image_reference_providers.md)。

## 规则范围

- 单独给出风格名也是有效输入。默认原样传递用户整句，并加入保护项。显式调色动作可在界面核对。
- 曝光与阴影亮度分开。「曝光不变、阴影抬一点」保留整体曝光并允许提亮阴影。「暗一点、别太暗」允许轻微压暗。「整体暖一点、阴影偏冷青」分别指定整体与阴影的色相倾向。
- 每份 Image 指令都要求一套全图共用的颜色映射。相同输入 RGB 在任意位置得到相同输出，只按原有色相、饱和度或明暗调整。禁止按画面位置或对象选区、左右分色、镜像配色、局部渐变或补光。通过同一映射保留自然肤色和皮肤纹理，黑白时保留肤色对应的明暗层次。保留人物身份、构图、裁切、物件、原有光源的数量、位置与方向，以及高光和阴影的形状和分布。未要求调整曝光时保持接近原片。赛博朋克的红蓝对比只作用于全图已有的红蓝色域，禁止新增霓虹灯、红蓝光源、光晕或重打光。需要选区、替换内容或合成纹理时，提示该动作需要单独编辑。
- 转译产出文字。拟合 LUT 前，把 Image 返回图与上传图对照，检查同类颜色在不同位置是否有一致变化。将明显的局部染色、左右分色、镜像配色、重打光或新增光源标为不通过。保留原始返回文件，修订指令后选用通过检查的参考图。

## 选择提示方式

离线页面可直接将用户原话与固定保护项组合为提示词。已有可信风格样张时，可单独附上定性的颜色或反差方向。用户明确指定的调色动作、曝光、肤色和原始照明优先。

准备给 Image 的 JPEG 时，默认最长边为 1080 像素，可按需求选择最长边 256 像素的轻量输入或最长边 3840 像素的 4K 输入。缩放保留宽高比，原图比所选尺寸小时保持原尺寸。返回图的实际尺寸由 Image 工具决定。

代理可以用 Node.js 读取同一个编译器的结构化结果。

    node "<skill>/assets/color_prompt_compiler.js" "整体暖一点，阴影偏冷青"
    node "<skill>/assets/color_prompt_compiler.js" --strategy guided --guidance "保留日光的明暗关系，让已有暖红更清晰、偏冷色更干净；全图同类颜色同步变化。" -- "徕卡风格"

只在状态为 ready 且动作符合原话时使用结果中的 prompt。该字段保存为 UTF-8 文本后，由 text_style_lut.py prepare 的 --image-prompt-file 参数接收。命令行 stdout 为 UTF-8 JSON。如无 Node.js，可打开离线页，或按通用转译 Prompt 处理原话。

## 联网样张速查

风格或来源需要解释时，按[自动搜索与选图流程](style_reference_search.md)执行，再把证据转成原片可以实现的全局配色动作。仅调整明确的颜色、明暗或曝光时可直接转译。
