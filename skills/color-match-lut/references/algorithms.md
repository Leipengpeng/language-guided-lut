# 多图 MKL/Oklab 的计算与边界

每张图片先 ICC 转为 sRGB、EXIF 转正，拟合视图最长边默认 1024。使用确定性的像素步长，目标约 8 万个样本（严格少于 16 万）；采样数不决定图片权重。变换到 Oklab 后，计算每张图的均值 μ_i 和样本协方差 C_i，加 `1e-6 I`。不同分辨率图片默认等权，也可以显式加权。

内容集合与风格集合**分别融合**为一个 Gaussian，然后求共享 MKL 映射。摄影师风格稳定和内容曝光稳定是用户对素材的假设，不是从未配对照片中可证明的事实。内容、主体面积和光照都会影响全图统计。

## 五种融合方法

两侧各自归一化权重 w_i，总和为 1。以下运算均在 Oklab 中完成，不能直接对输出 JPEG 或 `.cube` 文本做平均来替代。

### pooled：混合分布统计

`μ = Σ w_i μ_i`

`C = Σ w_i [C_i + (μ_i - μ)(μ_i - μ)^T]`

把各图片拟合得到的 Gaussian 当作混合分布，再取混合分布的均值与协方差；它与直接拼接等量像素的总体统计思路一致，但保留每张图已做正则化的样本协方差。亮、暗图片的均值差异会扩大最终方差。这样既可能得到更丰富的跨度，也可能把拍摄条件差异当作风格。

### mean-cov：统计量算术平均

`μ = Σ w_i μ_i`，`C = Σ w_i C_i`。

保留平均的图内对比和颜色相关性，不把图与图之间的曝光差异额外加入协方差。这不是对图片本身做均值。

### bures：Gaussian Wasserstein 重心

均值仍为加权平均。协方差求使各 Gaussian 的加权平方 W2 距离最小的重心。

使用 Álvarez-Esteban 等的固定点算法：给定当前 S，令

`Q = Σ w_i (S^(1/2) C_i S^(1/2))^(1/2)`，

`S_next = S^(-1/2) Q² S^(-1/2)`。

相对步长小于 `1e-9` 且固定点残差小于 `1e-7` 时停止，最多 256 次；失败明确报错，不静默退回别的方法。若协方差为可交换的对角阵，其每轴标准差是加权平均，而不是每轴方差的算术平均。

依据：[A fixed-point approach to barycenters in Wasserstein space](https://arxiv.org/abs/1511.05355)，Álvarez-Esteban、del Barrio、Cuesta-Albertos、Matrán，2016。

### robust-bures：稳健加权重心

本项目的工程启发式，不能等同于经过定理证明的 Wasserstein 中位数求解器：

1. 求各图片 Gaussian 的两两 W2 距离，选择加权距离和最小的样本作 medoid。
2. 以到 medoid 的距离 d 求加权中位数和 MAD，阈值 `h = max(median(d) + 2.5 × 1.4826 × MAD, 1e-4)`。
3. 图片有效权重乘以 `min(1, h / max(d, 1e-12))` 后归一化，再求 Gaussian 重心。

两侧独立重加权；活跃图片少于三张时不执行降权。方法会抑制偏离多数样本的照片，但不知道偏离来自不良样本还是用户想保留的独特风格。所有实际权重记录在 JSON 中。

### pairwise：映射算术平均

每个源 Gaussian i 与目标 Gaussian j 都计算 MKL 的 `A_ij, b_ij`，用权重 `w_i v_j` 平均矩阵和偏移，得到一个共享的 `A, b`。这里是两组未配对集合之间的全组合，不把列表第 i 张当作对应图。

平均发生在 Oklab 仿射变换上，不在最终 RGB 图片或裁切后的 LUT 上。它一般不等于重心到重心的最优传输，也不保证平均后的映射精确匹配任何目标协方差；即使两侧是相同的多图集合，全组合映射平均也未必为恒等映射。

## MKL、强度与 LUT

源统计 `(μ_s,C_s)`、目标统计 `(μ_t,C_t)`，

`A = C_s^(-1/2) (C_s^(1/2) C_t C_s^(1/2))^(1/2) C_s^(-1/2)`，

`b = μ_t - A μ_s`，`f(x) = A x + b`。

求特征值时只对逆幂使用很小的相对数值下限。不能把嵌套协方差的正平方根固定截断到 `1e-6`，否则会人为放大色度。每个 MKL 分量检查 `A C_s A^T ≈ C_t`，相对误差阈值 `1e-5`。

来源：[Pitié 与 Kokaram 的 2007 年线性颜色迁移论文](https://www.tara.tcd.ie/bitstreams/ee98044d-2ef3-46cf-9e56-ee567085cd24/download)；颜色空间使用 [Björn Ottosson 的 Oklab](https://bottosson.github.io/posts/oklab/)。代码是本项目实现，不导入第三方追色仓库。

可分别在 L、a/b 上缩放 `f(x)-x`，再乘整体强度。转换回 sRGB 后裁切 `[0,1]`。强风格可能造成高光、暗部或饱和颜色裁切；指标记录的是数值状态，不是美学排序。

对 65³ RGB 网格求输出，按 R 最快、G 中间、B 最慢保存 `.cube`。随后从磁盘重新载入，以三线性插值套到每张内容图。LUT 是采样近似，不是对整个连续色域数学上无损；插值误差与已保存 PNG 的套用一致性分别记录。

所有多图方法在单图对单图时退化为同一个 MKL。`anchor` 只用每侧第一张非零权重图拟合。默认采用 Bures，用户可按照片实际效果选择方法。

## 共享滤镜的能力范围

共享 LUT 是固定的 RGB→RGB 函数。同样的输入颜色始终得到同样的输出颜色；不会识别天空、人脸或衣服，也不能根据每张新照片自适应曝光。用多图拟合可能降低单张样本偏差，但不保证更接近摄影师的真实意图。建议选同一风格系列、相似题材与拍摄条件；不要把不同摄影师的照片混入“同一摄影师稳定风格”的验证组。
